# homebrew-twistedkeg

Homebrew tap for Twisted Keg CLI tools.

## Available Casks

| Cask | Description |
|------|-------------|
| `kb` | A CLI for managing a local knowledge base database |
| `lnr` | A CLI for Linear project management — manage issues, projects, cycles, and initiatives from the terminal |

## Installation

```bash
brew tap misham/twistedkeg
brew install --cask misham/twistedkeg/kb
brew install --cask misham/twistedkeg/lnr
```

## Updating

```bash
brew update
brew upgrade --cask kb
brew upgrade --cask lnr
```
