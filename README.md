# homebrew-twistedkeg

Homebrew tap for Twisted Keg CLI tools.

## Installation

```bash
brew tap misham/twistedkeg
```

### Available Formulas

| Formula | Description |
|---------|-------------|
| [kb](https://github.com/misham/kb) | A CLI knowledge base backed by SQLite |
| [lnr](https://github.com/misham/lnr) | Linear CLI client for humans and LLMs |

```bash
brew install kb
brew install lnr
```

## Updating

```bash
brew update
brew upgrade kb
brew upgrade lnr
```
